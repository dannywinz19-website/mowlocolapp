MOWLOCAL LEADS — VERIFIED-LEADS BUILD

This package contains the complete website source code.

IMPORTANT
- There are no fake or sample leads in this build.
- The feed stays empty until a real, authorized source supplies a lead.
- Posts older than 20 days are automatically excluded by the site logic.
- Facebook and Nextdoor require approved platform access; this package does not bypass their rules.

RUN IT ON WINDOWS
1. Install Node.js LTS from https://nodejs.org/
2. Extract this ZIP.
3. Open the extracted folder in Terminal or Command Prompt.
4. Run: npm install
5. Run: npm run dev
6. Open the local address shown in the terminal (normally http://localhost:3000).

DEPLOYMENT
The project can be uploaded to a supported Node/Cloudflare host. GitHub Pages
cannot run this full Next.js/Vinext project directly without converting it to
a static-only build.
